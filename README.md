# X風ツイート・リプライメーカー

架空のSNS投稿・会話を作成する静的ウェブアプリです。歴史風刺「1936年にXがあったら」などに利用できます。

## 機能
- 親投稿と返信（返信への返信を含む）
- 表示名、@ID、プロフィール画像（ローカルアップロードまたは画像URL）、本文、日時、閲覧数、いいね、リポスト、返信数の編集
- 投稿の追加・削除・並び替え
- ダーク・ライトテーマ、PNGエクスポート（1～3倍）
- JSONで保存・読み込み、ブラウザのローカル保存

## 起動
`index.html` をブラウザで開きます。PNGの書き出しにはCDN経由の html-to-image ライブラリを利用するため、インターネット接続が必要です。外部画像URLは画像配信元のCORS設定によりPNGに含められない場合があります。ローカル画像アップロードを推奨します。

## GitHub Pages
リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を選びます。

公開ページの予定URL: https://azxcvba.github.io/x-thread-make/

※ GitHub Pages の有効化はリポジトリの管理画面で行ってください。これは実在する投稿を再現したものではなく、創作物の制作を目的としています。
